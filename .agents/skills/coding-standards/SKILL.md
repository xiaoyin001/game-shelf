# 编码规范

- 每个 Go 文件在 package 前以中文“文件说明”描述职责；导出接口和重要约束有必要中文说明。
- 入口文件只分发启动，业务、传输、存储职责清楚；不为未来需求预造接口或空实现。
- 新增配置字段同步类型、示例和含义；标准 JSON 不写注释。
- 并发共享状态应有明确所有者或同步；外部调用带 context 截止时间。
- 复用适合当前目标的机制，但旧版通过不代替本次验证。
- 不全量整理无关文件；Go 只格式化本次新增或实际修改的源码。
