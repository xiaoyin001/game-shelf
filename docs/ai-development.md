# AI 自主开发闭环

1. 读取 AGENTS.md、当前产品、成长记录、相关 ADR 和现场 Git 状态。
2. 选择一个当前必要且可判定的小阶段，写清验收，不一次塞完整产品。
3. 先记录技术选择的候选、理由与代价；更换方案保留旧理由与替代关系。
4. 在功能分支实现该阶段，同时增加适合当前行为的测试，不为未来阶段预建占位实现。
5. 运行本阶段全部相关回归；编译、静态检查、模拟与真实联机结果分开。
6. 失败继续修复；无条件验证时如实写明缺口，不制造“已通过”。
7. 更新成长记录的实际能力、命令、结果和限制，立即创建本地阶段 commit。
8. 进入下一阶段；最终版本重新做组合验收后，才快进到 master。
9. 展示最终提交、仓库/目标与验证；按 AGENTS.md 中 owner 的持续明确授权，普通快进 Push 至本仓库 origin/master 无需逐次询问，随后核对同 SHA 的 CI。授权撤回/超范围时停止；强推、删除/标签、其他仓库/分支、PR、远端配置、远端 CI 重跑/取消和部署另行授权。

本仓库不依赖特定 AI 产品或私人配置。AGENTS.md 是跨工具入口，.agents/skills/ 保存可复用方法；凭据、模型账号、本机备份与会话原文不入库。
