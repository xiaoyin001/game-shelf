# 产品目标：苔光原野

第一轮 2D 原型及 CI 的历史验收保留在成长记录。当前新增目标是**账号密码验证 + 真正 3D 浏览器联机游戏 + 服务端跳跃与实体碰撞 + NPC 对话与委托**；目标不代表实现完成，以 [成长记录](progress.md) 与 [实际验收](verification.md) 为准。

## 本轮必须可见
- 同仓提供可运行的浏览器 3D 客户端和 Go 四服务，真实 WebGL 场景、立体角色/资源、透视镜头，不用 2D 贴图伪装 3D。
- 有明确注册和登录流程；账号密码都必填，密码为 6–32 位 ASCII 英文字母/数字/英文符号、不含空格；页面拒绝中文键入与非法粘贴，HTTP 和 db 再严格校验，数据库只保存慢哈希。错误密码、未知账号和无密码均不能进入或顶号，正确密码重登可替换同账号旧连接。
- 两个独立浏览器用不同账号进入同一世界，看见彼此及权威移动。WASD/方向键移动、镜头可观察 3D 场景；不允许客户端任意瞬移。
- 空格跳跃；服务端统一裁定重力、站立/落地、角色之间与静态树木/岩石/帐篷/篝火实体/晶簇的碰撞，可站在实体顶面，离开支撑下落，不允许空中连跳或伪造高度。
- 世界频道文字聊天、共享晶簇 E 采集、共享冷却与本轮分数保持可用。
- 两位可辨认、有实体的 3D NPC：靠近 E 或按钮交谈，守灯人可接取“点亮营灯”委托，接取后采集两次、返回领取额外3分；巡林员提供可选择的探索提示。距离、进度、奖励由服务端决定，重复提交不重复奖励，对话/委托仅自己可见，分数仍共享；离开后本轮进度重置。
- 有附近交互提示、NPC 位置与委托日志，对话时不会误触移动/跳跃，Esc/按钮可关闭；窄屏能查看和点击对话。
- 退出移除、重新验证进入、同账号顶替仍可回归；窄屏不溢出，能完成注册/登录和观看场景。
- 原 TCP 认证/心跳/大厅接口保持可用，AI 可自主构建、测试每阶段并留下真实决策/成长提交。

## 数据与安全
旧 players 无密码试玩资料保留，不由公开名字认领或继承；新账号是新身份。账号跨 channel 唯一，不能通过换 channel 绕过同账号策略。

密码验证不等于公网账号系统：当前仍限可信本机 HTTP。没有邮箱/找回密码/MFA、生产 TLS/部署与规模安全承诺。

## 不扩大的边界
不新增战斗、交易、长期养成、跨服、自由飞行或后台自主代理。服务器 X/Y/Z 映射场景 X/Z/Y，以简化圆柱/盒体判定碰撞，不冒称网格级刚体引擎。静态景物不被推走或破坏；湖面是浅水地表，不实现游泳/浮力。NPC 为固定角色与预设选项，不含巡逻寻路或生成式 AI。分数、委托、位置、资源与聊天仍是临时沙盒；不冒称成熟 MMO。

新技术选择先记录 ADR，各完整阶段实际回归通过后及时提交；不把最终目标或计划写成已完成。
