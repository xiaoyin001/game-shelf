# 产品目标：苔光原野 · 限时配对挑战

2026-10-27 owner 明确确认以 **180 秒搬运配对消除、单人冲分、双人合作和独立排行榜**替换旧 NPC/寻宝/收藏主循环。当前目标不代表实现完成，阶段事实见[成长记录](progress.md)，实际运行证据见[验证](verification.md)。决策入口：[ADR-0035](decisions/0035-timed-pair-challenge.md)。

## 核心循环与固定规则
开始挑战 → 观察取物 → 规划搬运 → 配对连击 → 清盘补盘 → 时间结束 → 成绩/排名 → 一键再来。

- 每局固定 180 秒，不因配对或清盘加时。六种易辨物品分散到全图八区，每区一堆双层道具；每日UTC日/模式/规则/盘序确定性选点并抖动，同组公平一致，上层取走才开放下层，不要求跳跃，存在完整解。配对台固定 `(700, 350)`，需要规划搬运路线。
- 2026-10-28 owner追加[地图要求](decisions/0040-scattered-map-and-water.md)：移除无用NPC及身体；水池内地面步行速度55%，离水或跳起恢复，落水再减速。地图/减速改变冲分，规则升级pair-2，旧pair-1数据保留但不混榜。
- 每人手持 3 件，可选择投送到共享 5 格消除台。相同两件自动消除；满台接受能立即配对的投送，否则拒绝且保留手持。可把未消除物归还原位，但中断连击。
- 每对 100 分，10 秒内再次配对延续连击，从 ×1 起每次 +0.5，上限 ×3。超时或归还中断。地面、手持、台面全部清空，额外 500 分且立即补盘；清盘奖励不乘倍率。拾取/归还/搬运不刷分，到时未配对不扣分。
- 服务器裁定计时、归属、距离、遮挡、容量、分数和成绩，浏览器不可自报。反馈包含吸附碰合、微光、递进音效与清楚的倒计时/倍率/手持/台面/队友/结算。

## 首版完整边界与阶段顺序
1. 完整可玩的单人固定三分钟闭环，真实 3D 道具与操作、清盘、结算和重开；先在隔离环境验证，不动现有试玩服务。
2. 房间码加入双人，双方准备后开始。各自 3 格手持，共享盘面、台面、时钟、团队分数和连击，看到队友位置与手持；贡献只作说明。开局锁两名成员，不中途换人。原成员短暂断线可重连，计时不停；主动退出转练习、不提交正式双人榜。
3. 单人每日榜与双人固定组合榜分开；同一 UTC 日/模式/规则版本关卡序列与时长相同。单人按账号、双人按无序固定组合保留最高有效分，另展示个人单人最佳、最佳双人成绩。不提供永久速度/得分优势。
