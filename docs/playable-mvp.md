# 产品目标：苔光原野

这是本次重建的验收标准，不从目标列表本身推断通过。当前完成情况以 [成长记录](progress.md) 和 [实际验收](verification.md) 为准。

## 完成时必须可见

- 同仓提供可运行的浏览器 2D 客户端与服务器。
- 两个独立浏览器以不同名字进入同一地图，看到彼此。
- WASD / 方向键移动，其他玩家看到权威坐标更新，不能通过客户端任意瞬移。
- 世界频道聊天，所有在线玩家可见；消息是文字，不当成 HTML。
- 靠近共享晶簇按 E 采集，获得本轮分数，资源冷却后恢复。
- 离开移除角色，可以重新进入；同名重新登录顶替旧连接。
- AI 可以按仓库说明自动实现、运行、回归并提交每个完整阶段，决策理由与替代历史可追溯。

## 不扩大的边界

目标是达到既有可玩版本的能力与呈现，不在本轮新增战斗、交易、长期养成或后台自主代理平台。位置、分数和聊天属于临时沙盒，退出/重启重置；不能冒称成熟 MMO、大规模容量或生产账号安全。

技术方案随实现阶段比较和记录，不因为最终目标列在这里，就提前提交所有模块或把未运行功能写成通过。
