本轮要求的可玩能力已通过本地自动验收：真实浏览器进入同一地图、权威移动、文字聊天、共享采集、分数与冷却、离开重进、同名顶替，以及原 TCP 登录/心跳/大厅兼容。

产品是 MMO 方向的单世界可玩切片，不是大规模 MMO、正式账号或永久资产系统。负责人认可的旧版仅是验收对照，不作为新版测试证据。

### 真实依赖与协议

- etcd 租约实例注册/发现，MongoDB 驱动连接与 HTTP -> db 账号落库，重复登录身份稳定。
- Redis 单次 token 消费、过期/重放拒绝、原子顶替、旧会话不可续期和不可删除新映射。
- 原 TCP 认证、心跳和大厅列表通过。
- WebSocket：未认证/伪造/过期凭据、Origin、身份伪造字段、错误版本、超大包、二进制包、尾随 JSON、请求频率拒绝。
- 原连接退出不删除新角色，同名连接替换后快照可继续接收。
- 运行器发现占用端口明确失败，原监听仍存活；不通过复用未知旧二进制来证明当前源码。

### Go 世界与生命周期

- 单世界角色租约/顶替、独立快照、容量防护。
- 服务器时间限速、斜向归一化、高频/闲置不能瞬移、边界与非法方向拒绝。
- 聊天长度/频率/30 条历史限制。
- 并发共享采集只加分一次、重复/远程采集拒绝与 10 秒重生。
- 世界快照 protobuf 完整往返；连接取消和较短 context 截止时间生效。

### 真实浏览器 6 个用例

1. 两个独立 context 观察同一名单；离开移除并能重新进入。
2. 同名新会话顶替旧连接。
3. 真实键盘移动后，另一浏览器观察到坐标变化。
4. 聊天广播，HTML 字符串是文字，没有 img 节点、弹窗或 pageerror。
5. 移动后采集增加本轮分数，另一端可见且无法在共享冷却期重复领取；重进分数为 0。
6. 390px 窄屏无横向溢出，真实表单进入与地图显示可用，不代表触屏移动。

程序化原野的真实双人截图已生成并查看。截图/trace 在被忽略的 test-results/，HTML 报告在 playwright-report/，日志在 .local/logs/；上述文字和可复跑命令是入库证据，不依赖访问开发者机器才能理解。
