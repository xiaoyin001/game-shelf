# ADR-0019：近距离 NPC 对话与本轮采集委托

状态：采用（2026-10-22，本地 Linux 真实四服务、17/17浏览器、独立服务回归和全量 Go race 通过；未 Push）。扩展 [ADR-0008](0008-shared-gathering.md) 的本轮采集目标，沿用 [ADR-0017](0017-authoritative-jump-collision.md) 的共享场景、权威物理与临时数据边界。

## 背景
用户反馈玩法单调，要求加入可交互 NPC。只有装饰角色或一句固定提示不能形成新的玩法循环；需要明确的角色身份、可选对话和能完成的目标，同时不扩成长期经济或战斗系统。

## 比较
- 仅客户端摆角色、弹固定文本或自行发奖励：实现简单，但无法保证联机一致和奖励安全，不采用。
- 接入生成式模型或通用脚本/任务引擎：增加费用、外部依赖和不可预测文本，当前两个角色无需此复杂度，不采用；未实测性能/成本。
- 固定角色 + 服务端白名单对话选项 + 单个本轮委托状态机：采用。复用现有世界锁、采集和快照，能验证距离、进度、重复领取和退出重置。

## 决定
1. 守灯人「阿苔」提供采集委托与提示；巡林员「林哨」提供营地和晶簇知识。守灯人在540 / 500，巡林员在700 / 230，避开出生点北向常用通道；固定 NPC 定义随唯一 layout.json 下发，包含身份、职责、坐标与85单位交互距离；同 ID 圆柱实体参与既有碰撞，画面复用真实立体角色并用专属颜色、名牌和标记区分，不计入在线玩家人数。
2. 新增 interact / choose 意图，仅传 NPC ID 与选项 ID；gate 注入身份，lobby 在同一世界锁内检查会话、白名单和三维距离。无效 NPC、选项或远程请求明确拒绝，客户端不传文字、进度、分数或奖励。
3. 委托从未领取→进行中→已完成。领取后成功采集两次（可等同一晶簇重生或探索不同晶簇）才可返回守灯人领取额外3分；之前的采集不追计。进度最多2，重复接取不清零、重复完成不再奖励。委托不消耗既有分数，奖励计入本轮微光分数，不当作可交易晶簇库存。
4. Quest 进度随每次响应私下返回当前玩家，不广播对话或委托给其他玩家；Dialog 仅随交互响应返回，选项与文本均由服务器决定。公共分数仍跨端可见。离开、租约过期、换会话或重启重置委托，与现有本轮分数语义一致，不写 MongoDB/Redis 资产。
5. 靠近 NPC 时 E 优先交谈，否则仍 E 采集；明确显示角色名、距离和按钮，侧栏列出角色位置与委托进度。对话中清空/抑制移动与跳跃，Esc/关闭可退出；失去距离、断线或离开清理面板。表单/按钮操作不会误触玩法，全部动态文字使用 textContent。窄屏可查看和点击对话，但不承诺新增触屏移动。场景容器显式100%宽度，避免最小高度经宽高比撑宽内部内容、焦点滚动后裁切面板；只有文本变化才更新委托的状态播报。
6. 场景版本升级，协议只追加字段，四服务与静态资源必须配套构建。保持原 TCP、账号密码、多人移动/跳跃/碰撞、聊天、采集、镜头和无 GL 拒绝的完整回归。

## 代价、迁移与回退
角色固定站立，无巡逻寻路、战斗、交易、自由文本生成或长期养成；状态机只服务当前完整小玩法，不预造通用引擎。没有持久化迁移，不删除已有账号、数据或历史。回退需整套恢复匹配的布局/协议/客户端，不能仅隐藏 NPC 却留下空气墙。新画面与流程的性能尚未实测。

## 验证计划
- Go：距离/高度、未知角色/选项、先接取后采集、未达标提交、并发唯一奖励、进度上限、私有响应复制、退出/过期/顶替重置、NPC 碰撞与布局一致、protobuf 往返。
- 真实四服务：双连接完成对话/委托/领取、旁观分数与私有进度隔离，远程/伪造奖励拒绝。
- 真实浏览器：E 与按钮交谈、选项、Esc/关闭、输入隔离、双人奖励可见、巡林员提示、重进重置与窄屏；全部已有用例保留。检查真实3D截图。
- 回归中的真实共享冷却必须等自然重生，不清空资源；圆柱晶簇北侧会阻挡正南路线，返回委托使用真实跳跃越过后再等到可交谈距离，不假设实体能穿透。
- 当前已有本项目试玩实例占用默认端口；不接管、不按端口杀进程，使用本轮独立网络命名空间和空数据依赖验证，记录实际平台与未覆盖项。

## 实际验证
最终采用 [ADR-0020](0020-protobuf-scalar-presence.md) 的 protobuf v1.36.11 后，Windows 的 check/check:client/go mod verify 与 Linux 隔离环境的 check/check:client/test:all/test:services、全量 Go race 全部通过。浏览器17/17（2.2m），新增委托22.1s、巡林员5.9s、窄屏2.2s，保持30s上限、零重试与全部原14项；真实 NPC/奖励截图已查看。旧 protobuf 的17/17不冒充升级后的结果，升级后整套已重新执行。

单测覆盖三维距离/边界、非法选项、先接后采、失败/他人采集不推进、进度上限、20个并发提交只奖励一次、私有副本与会话重置；真实协议还验证 NPC 实体阻挡和伪造奖励字段关闭连接。晶簇自然重生、NPC站位与圆柱北侧绕行问题按真实行为修正，未关闭碰撞、放宽断言或删旧测试。

测试使用独立 Ubuntu22.04 工具容器网络命名空间，固定三依赖在同一命名空间的空 tmpfs 中运行，无主机端口发布；最终4个容器定向回收为0。已有 Windows 试玩服务、锁和开发数据保持不动。未执行新版原生 Windows 全套联机、完整 test:ci 的故障注入或远端 CI；不沿用旧结果。

## 重评条件
需要更多委托、分支剧情、巡逻寻路或长期背包时另立 ADR；持久化需幂等与崩溃恢复设计，生成式角色需单独费用/隐私授权。不能把当前固定对话宣称为常驻 AI。
