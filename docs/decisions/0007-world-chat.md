# ADR-0007：有界的世界文字聊天

状态：采用。

## 背景
在线与权威移动已完成，现在加入在线玩家间的基本交流，不扩展为持久社交系统。

## 比较
- 客户端各自显示或点对点转发：无法保证所有玩家看到同一条消息，不采用。
- 立即增加独立聊天服务与数据库历史：可扩展，但当前世界规模不需要，会增加存储和部署。
- 由当前权威世界保存短队列：采用，一致、可测且部署不增加，代价是重启后无历史。

## 决定
只保留最近 30 条，单条 1 到 140 个 Unicode 字符，单玩家两条至少相隔 800ms，身份和名字从已认证角色获取。
浏览器使用 textContent 创建节点，不把用户文字当 HTML；输入框聚焦清除移动键，Enter 可聚焦聊天，消息发送后回到地图。
protobuf 增加 Text 与聊天快照字段，保留既有字段编号，不改变在线和移动语义。聊天不进 MongoDB，不称为永久记录。

## 验证
可控时钟验证空/长消息、频率与队列上限；真实双浏览器发送文字及 HTML 字符串，另一端看见文字但没有生成 img 或执行弹窗，已有在线/移动/协议回归保持通过。

## 重评条件
需要离线消息、审计、私聊、跨世界或内容治理时另立 ADR，比较保留短队列与独立服务/存储的收益代价。当前开发体验不作生产聊天安全和治理承诺。
