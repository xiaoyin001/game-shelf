# ADR-0018：以真实原页重进验证采集，避免重复构建 3D 场景

状态：采用（Windows 与双 CPU 限制下 Linux 完整真实回归各14/14通过；尚未补推/云端复验）。保留 [ADR-0017](0017-authoritative-jump-collision.md) 的全部物理行为和验证标准。

## 背景
提交 a5963e3 推送后的 [CI 39741132203](https://github.com/xiaoyin001/game-shelf/actions/runs/39741132203) 中 source 成功，真实服务/协议与 13 个浏览器用例通过，只有采集用例超过原 30 秒限制。云端 trace 显示重新进入前多做一次整页导航：约 2.07 秒导航与 10.43 秒填账号等待；所有行为断言约 28.27 秒完成，在串行关闭浏览器时达到 30 秒。不能把本地通过写成远端通过，也不能用普通浏览器噪声日志猜测根因。

## 比较
- 增加测试时限、重试、跳过采集或关闭真实 3D：不采用，无法解决流程重复并削弱反馈。
- 修改游戏或更换远端 runner：当前没有业务断言失败证据，不采用。
- 采集用例按用户实际的“离开→原页面输入密码→重新登录”，两个独立上下文并行关闭：采用。减少该用例不需要的重复整页初始化，保持真实注册/密码登录/联机与场景；已有 presence 用例继续验证整页重载重进。

## 决定
1. 保留共享采集唯一奖励、另一端冷却拒绝、实体接触停止、截图和重进分数清零，原 30 秒限制、零重试和全部 14 项不变。
2. 退出后先验证对端确实移除角色，再使用真实原页表单和正确密码重登；同时验证自己和对端的权威玩家名单分数归零，不只看已经在断开时清空的 HUD。
3. 本地配套回归发现旧碰撞测试固定按键一秒时，实际距离仍47.18、尚未到接触位置。改为持续真实按键等待实际距离小于43，再继续施压确认不越过对方、保持距离至少39.99；原上限47收紧到43，不靠固定墙钟时长猜测输入帧数。
4. 只对采集用例的两个独立浏览器上下文并行正常关闭，不强制杀浏览器进程，不把清理挪出验收时限；不改业务实现、协议、碰撞或账号数据。

## 代价、迁移与回退
采集用例不再重复整页重载；重载场景仍由在线重进用例实际覆盖，没有减少行为范围。没有数据/依赖/配置迁移。回退只恢复此测试流程，不能重写已推送历史或沿用原 Push 授权；修复完成后补推须另行授权。

## 验证
实际完成 Windows 独立新卷 test:all，真实服务/全部协议与14/14（1.0m），采集6.0s；Linux 仅本次运行器/子进程限制为 CPU0,1 的独立新卷完整 test:ci，真实服务/全部协议与14/14（2.6m），采集15.7s、碰撞15.1s，正常与故障资源均回收为0。30s、零重试、真实 WebGL2 和全部用例保持；原页重进新增双方权威名单分数清零，presence 整页重载重进仍通过。只改测试/文档，Go 与客户端业务未变，Go race 复用同一业务版本 a5963e3 的云端 source 成功证据，本轮未单独重复 race。不更改共享 WSL、其他进程或远端 runner；本地压力结果不是 GitHub 复验，仍待新提交获授权后推送。

## 重评条件
若证据显示原页重进也有功能错误，修复对应行为并保留失败断言；若完整回归在资源约束下仍无余量，再按实际渲染/初始化证据优化，不能以删除既有用例或放宽时限交付。
