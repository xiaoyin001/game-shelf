# ADR-0030：普通快进 Push 的持续授权与跨会话仓库规则

状态：采用（2026-10-26，owner本次明确同意原待推送修复，并要求这类推送默认授权、后续会话不再逐次询问；本阶段尚未生成新最终SHA验收或远端结果）。仅替代 [ADR-0025](0025-push-verification-gate.md) 的逐次询问授权流程，提交绑定门禁不变。

## 背景
owner已明确将此类常规推送改为持续授权，并要求后续会话不再重复询问。只在当前对话口头答应不能供以后读取仓库的会话继承；AGENTS、技能和脚本目前仍提示逐次授权，需消除当前入口冲突。2026-10-23的62a0e17曾真实通过默认完整preflight，但24小时记录现已过期，且本次会新增规则提交，不能沿用。

## 比较
- 保持逐次询问：与owner最新明确偏好冲突，不采用。
- 仅记在当前会话，或修改机器全局代理/其他仓库规则：前者不能跨会话可靠继承，后者扩大任务范围，不采用。
- 把本仓库普通快进Push持续授权写入AGENTS、共享技能与文档：采用。明确仓库/目标、撤回和例外，供后续读取本仓库的会话使用；不声称能自动同步到所有无关仓库或覆盖更高优先级限制。

## 决定
1. owner已持续明确授权本仓库任务相关、完整验收通过的普通快进Push至`https://github.com/xiaoyin001/game-shelf.git`的`origin/master`。后续读取本仓库规则的会话无需逐次询问。每次Push仍展示最终提交、仓库/目标和本次结果，推送后实际核对同一SHA的CI。
2. 不包含强推、删除远端分支/标签、创建/更新标签、未知/不同仓库或分支、PR、远端配置、远端CI重跑/取消和部署；这些操作仍需专项明确授权。授权撤回/任务范围不明、远端非快进或更高优先级约束时停止，不把持续授权当任意远端写入许可。
3. 保留默认完整`npm run verify:ci`、干净最终HEAD、24小时提交/tree/报告绑定、真实refs/资源/零残留和pre-push。候选/单job/旧SHA/过期记录不能放行，不能`--no-verify`绕过，不引入文档-only捷径。
4. 同步当前入口与脚本提示，门禁仍只验证技术证据，不把owner授权自动化成布尔绕过项；授权由规则记录，不由机器验收授予。不修改全局AI配置或远端设置，旧ADR/成长记录中的当时逐次授权事实保留并注明替代关系。

## 验证
规则测试明确持续授权范围、后续会话、不逐次询问及危险/其他远端操作例外；原hook/时效/实际refs/非快进拒绝回归保持。先运行规则/运行器/客户端检查并提交，再在干净新HEAD默认完整preflight生成新记录，核对真实hook后普通推送并观察同SHA CI。旧62a0e17的2026-10-23报告不算本阶段新结果，不预填云端成功。

### 本阶段相关检查
2026-10-26实际`npm run check`（规则5/5、成长历史、Go格式/包测试/vet/构建）、`check:client`、`test:runner`通过。Windows运行器25通过、SDK专属身份1项明确跳过，原WSL进程组超时回收仍实测；合成样本和规则测试不代替最终commit的真实完整preflight。门禁只改提示，没有改变报告判据、refs校验或时效。新最终SHA的完整结果和远端结果仍由提交后命令生成，不预填。

## 代价、迁移与回退
需要多处当前入口一致更新；历史授权事实不重写。后续会话必须读取仓库规则，无法保证未读取规则的会话或无关仓库自动继承。owner可随时撤回，撤回后恢复逐次确认；不删除验收历史、凭据或数据。没有性能/成本横评，未实测。

## 重评条件
owner撤回/收窄授权、远端/目标分支变更、任务出现破坏性或超范围写入时重新取得专项授权；完整preflight或同SHA CI失败仍按原规则调查修复，不能以持续授权代替验收。
