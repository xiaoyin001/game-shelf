# ADR-0009：完成可验收界面与程序化原野呈现

状态：采用。

## 背景
共享在线、移动、聊天与采集已逐项实现和提交。当前仍是简易验证页面，需要达到本轮既有可玩版本的地图与操作呈现，并保持所有行为可自动验收。

## 比较
- 引擎或外部美术资产：可制作更丰富画面，但增加工具链、资源来源与人工装配，不是本轮需要。
- 将所有内容画在 Canvas：渲染统一，但表单、聊天和可访问性/测试定位更困难。
- Canvas 程序化地图与角色 + DOM 表单、名单、分数、聊天：采用，复用已经验收的呈现设计，所有视觉素材由代码生成，无外部美术依赖。

## 决定
界面分为共享地图、旅人/分数和世界聊天；保留原生 label/按钮语义、服务器坐标与名单数据属性，避免为测试开作弊 API。
用树木、营地、湖面、晶簇光晕和冷却提示完成画面，装饰不改变服务器碰撞或交互规则。窄屏支持查看和表单进入，不冒称已经具备触屏移动。
页面变化不修改权威世界规则；保留旧行为回归，并增加窄屏与实际截图检查。采用目标版本的外观作为验收参照，不把本次界面完善伪装为旧版原始开发历史。

## 验证
重新执行全部服务与浏览器回归，检查浏览器错误、文字聊天安全、共享采集/分数、重进与窄屏溢出，查看真实双人截图。不以截图好看代替行为验证。

## 重评条件
需要触屏操作、无障碍游戏操作、3D 或更复杂场景时另立 ADR。当前不引入场景编辑器、美术生成服务或生产端性能承诺。
