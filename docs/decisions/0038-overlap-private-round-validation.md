# ADR-0038：私有长回合与浏览器回归重叠，保留完整预算

- 日期：2026-10-27
- 状态：采用，实测后更新结果，不预填成功
- 替换：ADR-0037服务回归先全部协议再全部浏览器的串行调度；保留三个真实180秒、全部短协议与浏览器/故障/额外轮

## 背景
b421bc7默认干净HEAD verify:ci报告0951ba09失败：source/CGO race通过、真实协议194.374秒通过、第一轮25/25（3.7m）及预期故障清理通过，额外新DB轮8/25后总执行期限到达。不是某个业务断言失败，但整次不能放行Push，旧阶段25/25不能代替。旧试玩已获准正常停掉，无端口前置阻塞。

## 比较
- 保持串行并延长预算、减第二轮/长回合/断言、放宽浏览器或降画质：拒绝，改变验收边界。
- 无差别并行全部协议和浏览器：拒绝，短协议有共享大厅人数/碰撞/会话操作，不可相互干扰。
- 先完整短协议，再启动三个真实长回合，收到每局已进入权威私有作用域的明确测试信号后启动原单worker浏览器，并等待两者全部成功：采用。长回合大部分为真实时间等待，在同2CPU/4GiB下重叠，不增加实际CPU/GOMAXPROCS、不缩短180秒，不把并行宣称为统计性能横评。

## 决定
1. 默认test:all的verify入口按明确的三个完整测试名分层；短协议通过-run/skip正则保留所有其他测试与基础设施，长层-run同一精确集合、-parallel3。完整test:services仍独立执行全部协议，不分层。browser-only与额外新DB轮仍只跑完整浏览器，不重复长协议或故障。
2. 长测试只在收到真实服务器running私有局快照后输出测试控制信号；三个预期测试名全部出现才允许浏览器启动。生产代码没有新API/缩时/测试进度入口，失败/缺信号/30秒未就绪明确失败，不能用短睡眠猜已隔离。
3. 有界管理两个自建子进程：正常退出必须都为0；任一错误/退出/中断/未就绪即失败，并终止本次已创建的进程树后回收自建服务。POSIX自建独立进程组，Windows仅以已持有的child PID taskkill /T，不按端口/进程名清理；不吞失败或把取消当通过。清理监听/计时器，防止Go包装器退出但测试子进程存活。
4. 所有Go断言、三个180秒等待/保存/重登/练习拒绝、原25例/真实WebGL/阴影/碰撞/窄屏/错误断言保持；第一轮仍完整test:ci及预期故障，额外轮仍新库/四服务/25例。30秒/零重试/单worker、27秒余量、2CPU/4GiB/无swap与12/25分钟总预算不变。

## 验证
新增实际受管子进程回归：分段信号/重复去重/缺信号/非零退出/就绪超时/提前退出、成功双等待、失败与中断回收父子进程、快速退出无监听残留；命令分层正则锁定完整测试名和原全套入口。Windows和Linux分别实际执行进程树分支，单元合成信号只证明调度，不冒称游戏验收。

最新源码在真实四服务上完整执行test:all和test:services，三个回合仍实际180秒；正式提交后重新默认完整verify:ci，任何失败继续修复，不把本ADR或旧通过绑定成新HEAD证明。最终Push和同SHA云端核对遵守AGENTS。

### 实际阶段结果（2026-10-27）
Windows check/check:client/workflow、运行器31通过/SDK专属1跳过；Linux独立副本e9a975d2 check/check:client/test:all/test:services/全量Go race通过，运行器30通过/2项环境专属跳过。私有信号三项齐全后启动浏览器，25/25（3.7m、最慢17.5秒）；三个真实长回合与其重叠，180.2540/180.3038/180.1077秒分别完成单人/双人/练习的原断言。独立全量协议轮194.307秒通过，仍各完整180秒。日志 `.local/logs/overlap-full.out.log`，本轮4容器已回收为0，已有prepared镜像/缓存、SDK UID0，不是正式Push证明。生产/画质/配置预算未改；提交后仍需新干净HEAD默认完整preflight，不能复用b421bc7的失败。

## 代价、迁移与回退
增加小型测试子进程生命周期和显式私有就绪信号，必须保证名单与分层一致；只影响测试调度，不改产品/存档/协议。保留原失败报告与完整历史。回退恢复串行，不能取消预算失败记录。

## 重评条件
出现长层公共作用域干扰、遗漏测试/信号漂移、进程残留或总预算仍失败时新增决策；不放松验收或伪造通过。
