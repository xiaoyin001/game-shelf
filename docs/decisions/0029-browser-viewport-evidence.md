# ADR-0029：玩法取证保持真实视窗，不为整页截图临时改变布局

状态：采用（2026-10-23，保持真实视窗的完整候选已通过，最终commit仍需正式记录/新SHA云端验收）。接续 [ADR-0028](0028-ci-dependency-io.md)，保留所有玩法/WebGL2断言与30秒/零重试。

## 背景
452c7bb正式默认完整验收第一轮19/19通过，第二轮NPC/真实3D分别在30秒失败（报告含5秒收尾显示35s），随后全job触及原预算；未生成有效推送记录、未Push。

保留并解开本轮trace：NPC采集2/2、返程、唯一奖励5分和旁观5分均已成功；fullPage截图耗6.846s，随后关闭对话/离开/密码重登各约2.5–3s，不能声称返程仍被晶簇阻挡。3D的全套镜头/位移在截图前成功，两次fullPage截图各4.286s/4.282s，后续真实lose_context约3s，最终正常关闭又到期。不是仅由mailbox日志推断GPU崩溃，也没有查明全部宿主调度原因。

## 比较
- 增加时限/重试、删截图/业务/上下文丢失断言：不采用。
- 降低画质/FPS、关闭真实阴影或替换WebGL2：对真实玩法影响更大，当前不采用。
- 玩法截图保持当前实际viewport：采用。桌面1440×1080内已有真实canvas、分数、NPC对话/委托、旁观名单；整页footer/聊天不属于这些图的验收断言。截图保留但不为取证临时扩大布局；视窗/窄屏响应式仍独立全量测试，不伪称当前图包括屏外内容。

## 决定
只将NPC委托/提示与3D两张证据图明确设为`fullPage:false`；保留两次独立3D图及NPC奖励截图，不使用隐藏canvas/冻结渲染/修改游戏状态/跳过资源。原相对镜头移动、GL深度/尺寸/丢失、真实阴影渲染、委托/隐私/分数/重登及所有等待断言保持。

这可避免整页取证时临时改动视窗尺寸的风险，实际耗时收益尚未验证；不以该推断证明所有超时的唯一原因。普通UID1001父进程的Docker权限配置不变，原失败记录仍有效说明不稳定。

## 验证
默认完整source/race、原test:ci与额外新DB所有19例，仍要求27秒本地余量、零重试/跳过和零残留；读取截图确认canvas、对话、委托和分数仍完整可见。候选通过后提交，在干净最终HEAD再次默认完整验收，不能沿用452c7bb或候选生成推送记录。新Push需新授权，原远端失败不改写。

### 实际结果
候选treebc0c63e38c96e703d2a4b689eb59497f0f3c1355默认完整preflight退出0：source实际CGO=1全量race163.572s；原test:ci19/19（3.6m）＋额外新DB/新四服务19/19（3.5m），最慢22.349s/20.870s，可玩总609.536s（含准备621.989s），原12/25分钟与全部限额不变。新空job工具缓存、固定基础镜像层已有缓存，两轮npm ci仍执行，全部本轮项目/卷/网络0。

实际查看第二轮NPC/3D视窗图：WebGL2场景、NPC对话、委托完成、5分、旁观名单完整可见；没有屏外footer/聊天下半部，不把它称整页截图。没有单独提取成功截图耗时，也没有证明宿主调度是唯一原因；以完整原断言两轮实际通过为准。该候选不生成推送记录，452c7bb正式失败保留；只补事实文档后提交，再对最终HEAD默认完整验收。

## 代价、迁移与回退
玩法证据图不含屏外footer/聊天，不能用于宣称整页无裁切；响应式断言独立保留。无产品代码/数据迁移，可回退截图选项；若仍超时继续依据新trace定位，不能反复择优重跑。

## 重评条件
若视窗截图仍因GPU/宿主调度卡住，记录实际取证/渲染开销后再决定产品优化；若屏外元素成为新增验收目标，为该目标单独安排取证，不把当前viewport图伪称整页。
