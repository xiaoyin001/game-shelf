# ADR-0021：服务器权威的低台阶迈步

状态：采用（2026-10-22，Windows源码/客户端检查、Linux真实四服务/18项浏览器/独立服务回归/全量Go race通过；未Push）。替代 [ADR-0017](0017-authoritative-jump-collision.md) 中“所有非零高度侧面都完全阻挡步行”的行为，保留重力、跳跃、支撑、实体碰撞与权威坐标。

## 背景
用户反馈极矮石头也完全挡路，希望像人走楼梯一样自动迈上低台阶，只有高台阶/高墙才需要跳跃等额外手段。现有圆柱/盒体能站在顶面，但地面移动遇到任何侧面都只阻挡或滑动。

## 比较
- 保持旧方案，所有非零高度都必须跳：不符合体验要求，不采用。
- 直接忽略低物体碰撞：会穿过石头、脚陷进实体，不采用。
- 客户端自动抬高或接入完整刚体/角色控制器：前者破坏权威同步，后者扩大依赖和迁移，当前不需要，不采用；性能/成本未实测。
- 在现有服务器分步移动中加入受限 step-up：采用。遇到阻挡时检查站稳、局部高度差、目标顶面和头顶空间，通过才将角色迈到真实实体上。

## 决定
1. 每级最大迈步高度为18个世界单位（角色高66）。按当前脚底到目标实体顶面的高度差比较，等于18可上，超过则阻挡；不是按绝对海拔限制，允许连续走多级台阶。当前6–8高的石头和12高的篝火实体可迈上，50高晶簇、60高帐篷、树干和角色仍不能直接从地面走上。
2. 只有 Grounded 且当前确有支撑、发生非零水平位移时才尝试。空中、起跳中、已走离边缘、原地/零时间输入不能借此爬墙；只把静态非NPC实体作为迈步候选，不把玩家/NPC当楼梯。无新客户端高度/速度字段。
3. 仍按原水平时间预算和不超过3单位的小步行走。每小步先尝试普通移动，再尝试迈步，最后沿未阻挡轴滑动；失败的尝试不改变任何坐标或速度。迈步检查抬升扫过的身体空间、目标位置所有实体/玩家和世界高度上限，不能低石旁边直接穿过高墙或挤进头顶的人体。
4. 成功时脚底到达顶面、站立且竖直速度为0；可以停留、继续上一级或从顶面跳跃。走下/走离顶面继续沿用真实重力落地，不把高处边缘自动吸附为地面，也不扩大水平速度或实现自由攀墙。
5. 前端继续插值权威高度，不自行预测迈步；仅补操作提示。场景版本升级，既有布局不删石、不缩碰撞体、不为测试新增假地形；真实回归使用现有低石与较高晶簇，连续阶梯/头顶/阈值边界在单测夹具验证。

## 代价、迁移与回退
仍是圆柱/盒体的离散接触模型，不是斜坡/网格级脚部IK、攀墙动作或任意地形引擎。较矮实体边缘存在角色足迹近似，渲染按已有插值平滑显示；没有性能横评。无数据库/账号迁移，临时世界规则变更需成套构建重启。回退恢复匹配的物理/场景版本，不能只隐藏高度动画或把低物体改成空气。

## 验证计划
- Go覆盖圆柱/盒体、低于/等于/超过18、真实顶面与停留、连续台阶、走离下落、从顶面起跳、空中/零输入/频发不抬升、头顶/高墙/玩家/NPC/世界上限拒绝、斜走滑动、混合随机动作不穿透。
- 真实服务和双浏览器不按跳跃键步行上现有低石，自己与对端看到脚底高度和站立，停留后能走过并落地；较高晶簇仍阻挡且可跳过。全部原17项、30s上限与零重试保留。
- 现有试玩运行中，不接管或清库；沿用独立网络命名空间/空依赖做真实回归，明确平台、清理和未覆盖项，通过后本地提交。

## 实际验证
- Windows `npm run check` / `check:client`通过；Linux独立Ubuntu22.04网络命名空间的同款检查、`test:all`（真实三依赖/四服务/全部协议与18/18浏览器，2.6m）、独立`test:services`、全量`go test -race -count=1 ./...`通过。
- 新增双浏览器用例13.8s，全程不按跳跃键，自己/对端看到现有rock-4的8单位高度与站立，真实WebGL模型抬升、停留300ms不下陷、走过落地；截图已查看。原17项、30s上限、零重试与较高晶簇/玩家阻挡断言原样保留。
- 单测实际覆盖两种形状、18边界与超界、三级相对台阶、顶面跳跃/走离、空中/无支撑/原地/同时间洪泛、抬升位置与目标位置的头顶玩家、低物旁高墙、NPC与世界高度上限、同输入包跨空隙禁止迈步和斜向速度；既有1200步随机不穿透继续通过。
- 验收期间保留运行中的试玩与开发数据；只使用本轮空tmpfs依赖，最终自建4容器残留0，无主机端口发布。未执行新版原生Windows全套联机、完整test:ci故障注入或云端CI；18单位为当前固定规则，未实测与其他控制器的性能对比。

## 重评条件
需要可配置步高、斜坡、足部IK、攀墙动画、移动平台或复杂地形时，再比较专用控制器与资源/物理引擎方案；任何自动迈步穿透或空中增高必须保留回归并修复，不能靠关闭碰撞放行。
