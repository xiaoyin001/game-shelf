# ADR-0031：两步寻宝与账号级持久收藏册

> 2026-10-27：玩法入口由 [ADR-0035](0035-timed-pair-challenge.md) 替代；保留本记录、旧存档与历史验收事实。

状态：采用（2026-10-27，先决策后实现；本地真实四服务/三依赖、三条完整探索、20/20浏览器与Windows全量Go race已通过；新SHA共用入口与远端尚未验收）。有限替代 [ADR-0008](0008-shared-gathering.md)、[ADR-0019](0019-npc-interactions.md) 的“所有玩法进度均为本轮数据”边界；原分数、采集委托、位置、聊天与资源重置语义保留。

后续[ADR-0032](0032-collection-camp-display.md)新增固定槽位微光展台，使用schema2并兼容读取本阶段1档；本阶段的三条路线和收藏语义保留，原阶段验收事实不改写。

## 背景
owner要求开始实现上一轮建议的轻探索、收藏与营地生活。只有加分和退出即失去的委托难以形成个人积累。本阶段先交付完整的“NPC领线索→两步实地调查→收藏册留存”小闭环；营地展示另立下一阶段决策，不预置未实现的资产字段或通用任务引擎。

## 比较
- 保持临时分数、增加更多同类采集委托：复用多，但无法留下成果，不采用。
- 浏览器localStorage保存收藏：跨端丢失且可自行改写，不采用。
- 开放背包、货币、交易、随机掉落和每日任务：扩大一致性和内容负担，本轮不采用；性能/成本未实测。
- 固定三条各两步的探索故事，db专有MongoDB文档，lobby权威验证，私有收藏册：采用。既有移动、NPC、跳跃与场景可直接复用，有限内容如实呈现，不声称已验证长期留存。

## 决定
1. 三条依次解锁的路线分别为营地旧铃、湖畔来信、晶簇风笛；每条先调查线索再找到收藏，不使用随机低掉率或现实时间门槛。最后一条必须实际跳上既有晶簇并站稳。首版固定路线，暂不宣称每日变化或无限内容。
2. 阿苔与林哨均可通过固定选项领取/回顾当前线索；离NPC太远不可领取。用F或“调查线索”按钮发送无目标/坐标/奖励的explore意图；服务器检查当前路线、步骤、三维距离和站立状态。E的交谈/采集优先级保持不变。
3. 个人路线标记为无碰撞的线索提示，仅靠近时在真实3D中可见；不移动或删除现有实体，不改变物理。标记和进度不广播给其他玩家；不抢共享资源，同一收藏只记录一次。
4. 新建field_books集合，以认证产生的user_id为唯一_id，保存schema=1、revision、found、active、step。读取缺失文档表示空册，不写默认账号。保存使用revision条件的单文档原子CAS与majority+journal确认；初次upsert的重复键视为冲突。有限状态和内容ID由db再次校验，未知/损坏数据拒绝加载而非清零覆盖。原accounts与players不迁移、不删除。
5. 进入世界先读取存档，读取失败拒绝进入；进度变化先落库后确认，不在退出时异步刷盘，不把Redis当长期存储。存储错误不发成功收藏，写入结果不确定时重新读取以恢复权威状态，仍提示操作未确认，允许重试或重登。
6. 同账号请求使用固定数量的分片锁串行化，包括进入、旧连接离开和持久操作；存储I/O期间释放世界锁，其他账号仍能移动。重新取得世界锁时核对会话；lobby→db调用限2秒，外层gate原3秒不变。当前仍只允许一个ready lobby，不宣称跨服资产一致性。
7. 追加内部protobuf与WebSocket私有book字段，浏览器不能传入found/revision/step。仅db连接MongoDB，lobby经发现与内部TCP读写。三条故事和奖励内容由Go端固定目录派生，客户端只呈现，不自判成功。场景版本升级并保持四服务配套重建。

## 验证
- Go：三条路线/两步状态转换、距离/高度/站立、未知选项、重复动作、并发唯一收藏、私有响应副本；离开/顶号/过期后恢复，存储失败与不确定提交、CAS冲突、世界锁不被I/O阻塞。
- 真实MongoDB/四服务：完整探索与重登，另一账号不获得进度，实际文档持久化；新Store/新World从同一真实文档恢复；并发CAS只有一个成功、损坏数据拒绝、伪造字段拒绝。只使用本轮测试账号/独立依赖，不清开发库。
- 真实浏览器：NPC领线索、键盘/按钮两步调查、收藏与故事、退出密码重登和线索续接、另一个账号私有状态、3D标记与窄屏。保留原19项、30秒/零重试、27秒本地余量与原总预算；新用例短小自洽。
- 每阶段执行check:workflow、check、check:client、test:services、test:all及全量Go race；完成后更新成长记录并及时本地提交，最终干净HEAD另外完整verify:ci后才可普通Push。

### 本地回归发现与修正（实施中）
- 首轮原巡林员输入隔离用例失败：新增选项排在首位，响应后的默认焦点让Space选择了寻宝页。将新选项追加在原选项之后，保持原有默认操作和全部旧断言。
- 第二轮原聊天用例注册收到HTTP429，trace明确为真实IP认证限频，而不是WebSocket/收藏服务错误。新增集成测试沿用了会先注册再登录的旧帮助函数，产生无必要的双倍认证请求。新增用例改为直接使用注册已经返回的有效token；需要重登的步骤仍实际验证密码。不清Redis、不放宽120次/IP/分钟或12次/账号/分钟，不增加测试重试或超时。

## 代价、迁移与回退
新世界进入依赖db在线，持久动作增加同步I/O；分片锁碰撞可能造成短时等待，没有容量/性能横评。只有三条有限故事，不含经济、自由建造、钓鱼、种植或后台AI。回退旧四服务可保留但不使用新集合，不删除收藏记录；不能把长期收藏暗中当成本轮分数清零。营地装饰下一阶段另立ADR并添加实际可用字段。

## 重评条件
需要更多内容、随机路线、多世界、交易、可消费物品或持续运营时重新评估内容版本、幂等操作日志和存储方案；真实试玩后评估可发现性和重复游玩意愿，不用代码完成宣称留存成功。
