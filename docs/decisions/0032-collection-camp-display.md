# ADR-0032：收藏解锁的固定槽位微光展台

状态：采用（2026-10-27，先决策后实现；Windows真实服务、20/20浏览器、独立服务回归与全量Go race已通过；阶段提交前尚未执行新HEAD共用preflight与远端）。接续[ADR-0031](0031-persistent-field-book.md)，只替代其存档schema=1及“尚无营地装饰”的阶段边界，原探索和本轮分数语义不变。

## 背景
第一阶段已交付并提交e61d565，下一阶段让收藏产生可展示的成果，形成“找旧物→读故事→解锁摆件→营地布置→查看朋友成果”的小闭环。地图只有单一共享营地，不应为首轮装饰引入地块争抢、100座实体房屋、动态碰撞或新世界路由。

## 比较
- 维持只有收藏数字与故事：可留存但缺乏可见成果，不采用。
- 自由建造、独立房间、物理家具或永久地块：增加空间、权限、碰撞与迁移成本，本轮不采用；性能/成本未实测。
- 只在DOM里显示“已摆放”：不能满足3D成果展示，不采用。
- 营地固定位置的三个无碰撞微光投影槽位，每人保存自己的布置，浏览者选择查看哪位在线旅人的投影：采用。直接复用原野3D和权威快照；明确这是个人展台投影，不是假称每人已有独立房屋或同时占据同一物理地点。

## 决定
1. 展台中心730/530，左/中/右槽位700/530、730/530、760/530，位置/ID由唯一scene.json提供。三件收藏分别解锁归途铃灯、湖色花盏、晶叶风铃；均为无碰撞装饰投影，不遮断路径、不消耗分数或物品。
2. 玩家站稳且距中心三维距离不超过110时可布置自己的展台。decorate只接受slot_id/decoration_id，不接受owner_id、位置、解锁标记或奖励；服务器验证白名单与真实收藏。空ID表示收起；同一摆件放到新槽位时自动移出旧槽位，替换旧投影也不会丢失解锁。
3. 收藏线索与展台使用侧栏页签切换，避免布置控件挤出常用视窗；select焦点不触发WASD/跳跃。私人book追加可用摆件与自己的布置；公共世界快照仅追加在线旅人的owner_id/name/slots，不广播收藏步骤/线索/未发现故事。客户端可选择观看任一在线旅人的展台，只有当前选中自己的展台才开放编辑控件；最终权限仍由服务端身份裁定。
4. 真正3D模型按服务器确认的slot/decoration呈现，不先画草稿再宣称保存。切换观看者、退出和离线移除旧GPU资源；场景版本升级，四服务成套重建。选择观看者只是当前浏览器视角，不是传送、跨服或持久地块。
5. Journal追加有界camp数组，复用原同步CAS和错误恢复。新服务读取schema=1/2，旧1档缺少camp视为空展台；首次合法写入保存schema=2，保留revision和原收藏，不批量迁移/清库。保存过滤只接受1/2，未来未知版本拒绝。旧31服务拒绝读取2档，因此不能以旧服务继续写入后丢失新增字段；回退须部署懂2档的禁用装饰版本或经过单独授权的保留字段迁移。
6. db再次校验槽位、摆件、唯一性与收藏解锁，重复/伪造操作不能绕过。revision达到明确上限时拒绝再写，不能生成下一次无法加载的坏档。无消费经济、交易、挂机产出、强制签到或付费资源。

## 验证
- Go：未解锁/未知槽位/远距离/空中拒绝，布置、跨槽移动、替换、收起、重复、存储失败、并发操作、私人/公共副本与退出恢复；schema1读取与2迁移，未来版本与非法camp拒绝。
- 真实四服务/MongoDB：实际探索解锁后近距离布置，另一账号看到公共展台但不能替他人修改；新Store/新World恢复布置，实际文档schema2；保留全部原集成断言和真实认证限频，不添加多余注册后登录。
- 扩展原收藏独立用例：真实寻宝获得摆件后，增加表单布置与收起/重新摆放、短时加入第二浏览器切换观看、真实3D计数与样式、原密码重登同时验证收藏/布置恢复；避免新用例重复整段寻宝。窄屏另在原响应式用例检查控件布局。原20项与全部断言完整保留，30秒/零重试、27秒本地余量、2CPU/4GiB与总预算不变。
- 先执行check:workflow/check/check:client、独立test:services、test:all和全量Go race，通过后立即本地提交；最终干净HEAD完整verify:ci与真实pre-push通过才按持续授权普通快进Push，随后核对同SHA CI。

### 实施回归现场
- 首轮Windows完整20/20、独立服务和race通过。随后只调整槽位标签列宽并跑两项布局回归，寻宝的首次F未推进；原trace显示松键时632.868/517.658距线索约32.95，残余移动到632.868/533.410后约35.50，已超服务器34步，180步可见标记并不代表可调查。
- 保留该失败现场，新增精确Go位置与34边界回归；新浏览器用例在调查前读取真实坐标，以实际键盘短步靠近并等待松键零输入生效。不是重复发送调查碰运气，不改距离/碰撞/进度断言，不加Playwright重试或放宽时限；仍保留F、按钮、两次密码重登、故事、布置/收起/参观与截图。

## 代价、迁移与回退
每个浏览者一次只在同一营地位置观看一位旅人的投影，没有独立家园/离线好友访问，也没有所有人的家具同时实体化。三种摆件、三槽位的有限组合不代表长期留存已验证。schema2会阻止旧版本进入此类账号，升级需四服务匹配；旧文档和开发数据不删除。暂未做容量、性能或成本横评。

## 重评条件
真实试玩需要更强空间归属、离线访问、更多槽位/内容、自由建造或多个世界时，重新评估实例/地块、持久权限与物理预算；如新用例或图形超出当前严格CI预算，先依据现场优化而不是删断言或盲目放宽期限。
