# ADR-0036：双人房间、准备与原成员重连

- 日期：2026-10-27
- 状态：采用，先实现并独立验收，不代表持久榜单完成
- 接续：[ADR-0035](0035-timed-pair-challenge.md)；替换其“单人局仅挂在线角色、断开即丢失”的局组织方式，单人计分规则不变

## 背景
单人切片8cc34cb已隔离验收。owner要求继续已确认的双人合作及后续榜单。现有试玩和数据库仍不动；普通最终verify:ci的端口保护拒绝是环境事实，不以隔离回归当Push证明。

## 比较
- 保持每个在线角色独立Round并互相复制：不能原子处理抢物/共享连击，断线会丢手持，不采用。
- 新增服务/分布式房间与跨lobby恢复：扩大首版范围，尚无多lobby路由或性能实测，不采用。
- 单lobby内由World统一持有房间、固定成员、共享Round与账号归属，在同一世界锁内操作：采用。沿用现有权威物理、计时和配对规则，外部网络身份仍只由gate提供。

## 决定
1. 每账号只能属于一间房，最多100间。六位加密随机房间码（无易混字符），只在本房成员快照公开；仅等待房可加入，最多两人。双方在线且各自准备后，房主显式开始。等待成员变更/断开清准备；房主退出时移交给剩余成员。房间/重开命令携带当前房间ID，物品命令继续携带RoundID，拒绝跨房/旧局残留意图。
2. 房间为可见/聊天/身体碰撞作用域；单人也用同一房间组织，但保持独立盘面及原单人断开中止边界。双人开始在安全的两个出生点落地，各自3格手持、共享16件盘面/5格台面/180秒/分数/连击。两名成员固定到结束，不能换人。贡献显示由谁完成配对，不作为另一个总分。
3. 断网/刷新/验证后的同账号顶号属于连接更替，不主动退局。双人原成员保留20秒单调时间窗口，手持/盘面/分数和截止不变，重登自动回房；身体离线移除，恢复时检查碰撞，必要时找附近安全落点。等待房断线清准备。过期即放弃席位，进行中的局转练习；归还该成员手持到原位并断连击，避免剩余成员无法清盘。
4. 明确点击“退出本局”或“离开世界”是主动退局，不可伪装成重连。进行中立即转练习，释放退出成员的手持，原成员也不能中途再加入。其他成员可继续练习到固定截止。结束后的主动离房不追溯改变已完成局的资格。
5. 资格分为eligible、reconnecting、practice。短断线到时尚未恢复时先保留原20秒窗口和结算，重连成功可确认资格；过期转练习，不因截止偷偷缩短重连承诺。此阶段资格用于真实UI与行为；还没有写榜，不把eligible描述为“已经入榜”。
6. 房主重开先回等待、清双方准备，重新双方准备再开始；新RoundID和新的固定成员快照，房间码保留。退出席位/旧聊天在等待成员变更或重开时清理，防止新队友继承旧私聊。无剩余有效成员时回收房间和索引；不清数据库。
7. lobby每200毫秒独立推进World.Tick，客户端不轮询也能截止/清理重连窗口。所有共享状态在世界锁内；无服务端测试缩时开关。协议新增字段号，不复用已停用字段。

### 首轮回归发现与界面收敛
首次隔离浏览器22/23通过；共享配对流程在巡林员实体边缘被阻挡：松键余量使北侧落点到y269，横移不能穿过y230的NPC圆柱。改走东侧明确留余量的真实路线，不删身体或放宽碰撞/时限。局中默认折叠准备名册和房间说明，保留可展开房间码，给倒计时、手持/台面与队友手持留出同屏位置；不通过缩小截图视窗取证。

### 阶段验证资源组织

探索时两个独立网络的工具容器分别绑0/1和2/3并发，各2CPU/4GiB，仍在4核WSL上出现多个基础浏览器超时与500ms窗口零绘制，两轮均失败；不拿其中协议180秒通过冒充整轮通过，也未实测证明唯一根因。最终改为无其他本任务浏览器组并发的单轮隔离验证，仍2CPU/4GiB/无swap、原30秒/零重试与完整断言，不改正式CI运行器或总预算。双连接协议工具持续消费双方真实快照，避免闲置接收缓冲后突发补发移动意图。

### 重连用例职责与真实公共协议准备

串行完整轮基础20例全部通过，新合作/重连两例仍触及30秒；不能把只取消并发称为已解决。比较延长时限/删手持断言、每例重复完整UI准备、将准备UI与已有对局的重连呈现分工：采用最后者。建房准备和退出仍各从两个独立真实表单完整开始，两表单独立并行；合作投送改用实际1–3/F键并从东侧让路，保留全部计分/手持/截图断言。重连例以真实HTTP注册、浏览器同源公开WebSocket认证/建房/双方准备/开局/真实方向移动/拾取准备一个已存在的对局，再用原账号的实际登录表单重新接入，完整断言局ID、截止、手持、对端归属与真实模型。没有种入进度、改坐标/时钟/成绩、生产调试入口、跳过或重试，公共协议路径另有完整180秒服务回归。

## 验证
- Go/race：固定两人成员、准备/房主授权、重复加入/满房/跨房动作、同物并发仅一人成功、独立三格、共享台面与连击、精确180秒、截止后的重连资格、20秒边界/租约过期、顶号旧清理保护、离线恢复碰撞、退出返还防死盘、重开/房主移交/回收与快照深复制。
- 真实四服务：两个账号建房加入/准备/配对、第三人隔离/拒绝、断开重登保留局与手持、主动退出练习。双人与单人完整180秒协议例并行等待，同样实跑180秒而非缩时；背景Tick在不靠客户端意图时结束局。
- 浏览器保留已有20例，增加双人准备、共享道具与队友手持/贡献、刷新恢复、退出练习和窄屏操作的真实回归。仍30秒/零重试/单worker；额外长观察不混称CI用例。新状态UI仍变化驱动，不降低画质/帧率/资源或门禁。
- 在独立源码副本/网络命名空间/临时空依赖执行check、check:client、test:all、test:services和全量race；旧试玩不动。阶段通过后本地提交，最终仍须干净HEAD的默认verify:ci与真实pre-push。

### 实际阶段结果（2026-10-27）
最终独立串行轮check/check:client/test:all/test:services/全量Go race全通过，浏览器23/23（4.1m、最慢21.3秒），两轮各完整单/双人180秒。日志 `.local/logs/coop-verified.out.log`，副本/任务7717a0fe为passed。实际2CPU/4GiB/无swap，沿用已有prepared镜像和缓存、SDK UID0，所有本轮容器0；不是冷工具/普通UID/故障注入/默认verify:ci。旧试玩四服务与数据不动，持久榜单未实现，阶段隔离通过不授予Push。详细失败、覆盖及未覆盖见[成长阶段35](../progress.md)与[验收](../verification.md)。

## 代价、迁移与回退
增加内存房间索引与重连状态机，须主动回收且不能让旧会话覆盖新连接。房间/未完成局在lobby重启时中止，不承诺跨进程恢复；账号/旧存档无迁移。回退到单人提交仅失去内存房间，不覆盖Mongo档。容量、性能和网络中断类型横评未实测。

## 重评条件
出现多lobby、跨进程恢复、四人/匹配需求、回收遗漏、资格争议或正式预算不通过时新增ADR；不以放宽计时、重试或删基础断言解决。
