# ADR-0039：WebGL2帧完成背压，保持画质与30/12fps目标

> 2026-10-28：[ADR-0041](0041-frame-observation-and-parallel-carry.md)仅替代固定500ms闲帧抽样方法；本记录的真实GPU背压、画质与FPS目标均不变。

- 日期：2026-10-28
- 状态：采用，修复验证中，不预填云端成功
- 替换：ADR-0022仅按JS时钟投递帧的调度；不替换其30/12fps目标、绘制内容或验收门禁

## 背景
91d0b85在干净HEAD默认preflight source/race与两轮25/25通过，真实hook放行后普通快进Push；云端同SHA CI40534173405仍失败：source成功，真实三个180秒通过，浏览器23/25（7.7m），3D/合作两例30秒超时。不能把本地两轮当远端成功，也没有远端重跑/取消权限。

已取真实job日志，制品仅范围读取失败两例的完整trace/错误上下文/失败截图，不声称25MB整份制品已下载。3D第二账号fill8.301秒、两张实际视窗截图4.069/4.110秒，主动loseContext与全部断言后close触及时限；合作配对/共享100分/贡献断言已完成，截图6.804秒，之后正常双context.close未在剩余时间完成。不能由mailbox/DBus日志断言唯一GPU故障原因。云端整体明显慢于本机，并非新成绩规则或配对断言失败。

## 比较
- 保持只按JS时钟提交帧：当GPU/软件驱动处理慢于CPU投递，允许命令累积；JS定时并不证明上帧完成，不采用。
- 降FPS/像素/阴影/几何、删截图或弱化/拆掉原完整3D与合作断言、延长30秒/重试/CPU/总预算：拒绝。
- WebGL2真实fenceSync非阻塞观察已提交帧完成，每窗口最多两帧在途，完成后继续按原30/12fps目标提交：采用。只对驱动未完成的工作施加背压，不冻结可绘制场景、不改变渲染质量/时间/网络100ms，也不冒称所有硬件达到目标FPS或已证明唯一性能根因。

## 决定
WorldView持有其WebGL2 context与本窗口帧fence；到绘制预算后先以clientWaitSync(timeout=0)回收已完成fence，若两帧仍在途则保留rAF继续观察，不继续堆积命令。renderer.render后插入fence并flush，成功提交才增长原绘制计数；不使用阻塞gl.finish/读回像素等待。窗口pagehide/上下文丢失时释放本窗口fence，异常仍明确3D失败，不伪装成功。

原场景、材质/阴影/分辨率、角色/道具、反馈、截图与全部原用例保持。增加只读在途/峰值指标，浏览器实测队列≤2、idle有真实新绘制且≤12fps预算、移动/镜头恢复活动及原GL/像素/物理断言；不开放可写游戏调试状态。

## 验证
先真实浏览器定向两失败完整用例及全部回归；同固定2CPU/4GiB/无swap，维持30秒/零重试/单worker和27秒本地余量。阶段通过后及时commit，新干净最终HEAD默认verify:ci、hook和同SHA云端均须重新核对；旧91d0b85实际Push及云端失败保持记录。不用本地改善直接宣称远端已修好。

### 实际阶段结果（2026-10-28）
Windows check/check:client/workflow通过，Linux独立副本240d57a9完整check/check:client/test:all/test:services/全量Go race通过；原25/25（2.3m、最慢13.0秒；3D9.3秒/合作13.0秒），仍三个完整180秒及全部原截图/断言，GPU在途/峰值≤2与真实idle新绘制均实测。另定向5/5通过。截图已查看，场景/角色/物品/阴影保持；单轮差异不称统计因果证明或云端已通过。日志 `.local/logs/gpu-full.out.log`、任务240d57a9为passed，已有prepared镜像/缓存/SDK UID0，本轮容器0，不是最终默认门禁。

## 代价、迁移与回退
多两枚GPU同步对象与一次非阻塞观察/flush。GPU不支持或失败须明确失败，不能用2D替代；WebGL2是既有强制要求。仅客户端调度，无账号/成绩/存档迁移。回退到原JS计时调度，不删除失败历史。性能/成本统计横评未实测。

## 重评条件
出现停绘/同步资源泄漏、交互饥饿、画质差异或正式云端/总预算仍失败时新增决策；不放松验收或复用旧SHA证据。
