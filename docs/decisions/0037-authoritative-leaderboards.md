# ADR-0037：权威结算、幂等成绩与独立每日榜

- 日期：2026-10-27
- 状态：采用，产品闭环已隔离验证；正式交付以最终HEAD门禁为准
- 接续：[ADR-0035](0035-timed-pair-challenge.md)、[ADR-0036](0036-cooperative-rooms.md)

## 背景
owner要求继续最后的持久成绩/两个榜单，并明确旧试玩现在可以停掉。已核实本仓库看护与四子进程，使用既有停止标记正常回收；只stop本仓库Compose依赖，不删容器/卷/账号/存档，不碰其他项目。

## 比较
比较保持内存成绩（不能重登保留）、客户端上传成绩（不可信）、Redis可变最高分再异步落库（增加双写一致性）、Mongo不可变权威回合记录并查询派生最高分：采用最后者。仅db持有Mongo句柄；lobby仍是唯一规则裁判，gate只接受查询意图，不接受分数/成员/局结束/时钟。性能/成本横评未实测。

## 决定
1. 仅服务器单调180秒正常time_up、资格确认的solo/duo回合入库。练习/提前退出/中止不入榜；双人截止仍在20秒重连窗口时等待原成员恢复，超期转练习。一旦截止时已确认资格，之后正常离房/断线不追溯失效。
2. World在同一锁内捕获深复制的固定名册、规则、开始UTC日、起止毫秒、分数/配对/清盘及贡献。完成后可立即重开/离开，待存结果独立于房间；外部I/O绝不持世界锁。队列满100时拒绝新开局，既有最多100房仍可完整结算，待存上界200，不丢弃已完成成绩来腾位。
3. lobby独立后台提交，单次2秒截止、失败5秒后自动重试，状态pending/saving/failed/saved明确呈现；只有Mongo majority+journal确认或相同已存在记录才显示saved。全局队列为当前lobby内存，不宣称持久outbox：确认前lobby异常退出可能丢未保存结果，界面不得先报保存成功；已确认记录重启后仍可查。服务关闭不保证补报未保存局。
4. Mongo新collection challenge_results，schema1，不改players/field_books/accounts。RoundID为唯一_id；重复相同规范记录幂等，冲突/损坏/未知schema明确拒绝，不覆盖。成员按账号ID排序产生无序固定组合键；校验身份/模式/固定时长/UTC日/计分与配对贡献一致性。新增内部协议编号，不复用旧号。
5. 每个UTC日、模式和规则版本独立榜，单人每账号、双人每固定无序组合仅最高有效分；同分按最早完成时间、组合键稳定排序，显示前20。开始日归属不因跨UTC零点结束改变。个人单人最佳/双人最佳从当前规则所有日期已保存有效记录派生，双人为团队分而非单人贡献。0分正常完赛也有效，不与旧采集分数混用。
6. 已认证用户可查solo/duo与有效UTC日期；身份由gate绑定，个人最佳只返回本人。显式打开/刷新榜单才查库，每账号800ms限频；不随100ms世界快照读库。不在失败时显示假空榜或旧结果为新结果。UI可切模式/日期、显示前20和两个个人最佳；结算单独显示真实保存状态。
7. 数据增长和聚合代价是不可变记录的代价。建立日/模式/规则/组合与个人查询索引；首版不做分页/赛季/删除历史/跨规则混榜，不作容量承诺。回退旧程序不会读新collection，也不得清理新成绩。

## 验证
Go覆盖准确截止/练习拒绝/冻结资格/重连窗口/离房重开不丢待存/失败重试/容量与深复制；真实Mongo覆盖幂等并发、冲突、最高分、同分、无序组合、日期/模式/规则隔离、个人最佳及新Store恢复。真实四服务180秒例增加保存确认、密码重登查询和榜单断言；浏览器保留原23例并新增真实空榜/切换/失败和窄屏查询，不用缩时开关、预制进度或自报分数冒充完赛。另行长浏览器观察不混入30秒默认用例。

完整阶段通过后及时本地提交。最终干净HEAD仍运行默认verify:ci、真实pre-push检查；固定SDK、2CPU/4GiB/无swap、30秒/零重试/单worker、27秒余量和总预算不放宽。普通快进Push仅按既有授权并核对同SHA CI；未有结果不宣称完整交付。

### 三个真实长回合的有界等待
首轮隔离真实服务三个180秒例均通过，但Go默认-parallel随2CPU只给两个测试名额，第三个晚180秒开始，协议包实耗374.179秒。比较删练习长回合/缩短生产计时、提高CPU/总预算、显式给Go三个并行测试名额：采用最后者（-parallel 3），只让三个真实I/O等待同时进行，GOMAXPROCS与容器2CPU不变，浏览器仍单worker/30秒/零重试。统一两个实际服务入口并增加命令参数回归，另实跑新入口；不将此称为性能横评或已经证明完整preflight满足预算。
