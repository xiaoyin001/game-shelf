# ADR-0015：用本地 Three.js 升级真正 3D 场景

状态：采用（Windows/Linux 最终真实服务/协议与 9/9 浏览器通过，Go race/产物漂移与故障清理通过；远端未复验）。仅平面、无跳跃/碰撞的边界后由 [ADR-0017](0017-authoritative-jump-collision.md) 替代，下文保留原阶段历史。替代 ADR-0009 的 Canvas 2D 世界绘制；保留 DOM 账号、名单、聊天、服务权威与阶段 14 的密码验证。

## 背景
新增目标明确要求把 2D 游戏改成 3D，而不是只美化登录或模拟透视。现有浏览器和 Go 四服务已能自动验收，可保留通信与权威玩法，独立替换呈现和镜头。

## 比较
- 用 2D Canvas/等角投影画立体图案：不是真正深度场景，不采用。
- Unity/其他桌面引擎迁移：引入独立编辑器、资源构建与客户端分发，现有浏览器验收需重建；当前无必要，不采用。
- 原生 WebGL：依赖少，但需重写矩阵、材质、灯光与资源生命周期，当前成本高，不采用。
- Babylon.js：功能完整，当前只需场景/角色/镜头，不增加整套编辑器和资源流程。
- Three.js 0.186.1 + WebGL2：采用，成熟透视场景、灯光/阴影和程序化几何，复用浏览器、Go 内嵌和 Playwright，不引入 CDN、付费模型或外部美术资产。

## 决定
1. npm 精确锁定 0.186.1；将官方 ESM 构建和 MIT 许可原样镜像到 client/web/vendor。显式同步命令生成文件，默认检查只比较已安装锁定版本的字节，不自动改文件；第三方代码不手改或格式化；上游 core 存在混合缩进，Git 空白规则仅豁免 vendor 原样目录，字节检查仍强制执行，第一方代码风格检查不减。
2. 不为两个模块引入 bundler/dev server，Go 仍能直接嵌入仓库内静态资源。升级依赖时同步版本、产物和许可，再完整验证。本次查询实际 0.186.1 npm 包只有非压缩 module/core，两文件约 2.12MB；采用原样镜像，不伪造不存在的 min 构建，也不只为压缩新增工具链。
3. 真正 PerspectiveCamera、3D 地面/树林/营地/湖面、立体角色与晶簇、灯光/阴影；右键环绕、滚轮缩放、R 复位、跟随自己的角色。无 WebGL2 必须明确失败，不能悄悄退回 2D。
4. 服务端 X/Y 映射场景 X/Z；WASD 相对镜头变换为输入向量，仍由服务器裁定位置、速度、分数、冷却。仅避免出生角色完全重叠，不新增垂直移动/跳跃/碰撞玩法；有变动补服务端回归。
5. 保留 DOM 表单、名单和公共权威坐标以便可访问/机器验收；不暴露可改世界的测试接口。静态几何复用/实例化，动态角色离开释放专属贴图/材质。首轮软件渲染用例接近原 30s 上限，因此使用轻量 Lambert/Phong、复用静态阴影且按角色变化限频更新、30fps 插值，保留真实 GL/深度和原用例时限，不把测试失败改成跳过。
6. 测试明确启用 Chromium 软件 WebGL2，真实创建上下文和渲染场景，验证双端状态、镜头相对移动/环绕/缩放、无外部资源请求及截图。软件渲染是实际 3D，不以改标签或假画布通过。

## 代价、迁移与回退
Go 二进制增加浏览器模块体积，WebGL2/GPU 或软件渲染成为前提；程序化美术与地面移动只是 3D 联机沙盒，不承诺成熟 MMO 美术/性能或垂直物理。静态依赖同步增加一项字节检查，避免 package-lock 与内嵌资源漂移。

本轮不迁移账号或删除数据。旧 2D 实现和选择保留在历史；回退呈现时保留阶段 14 密码验证与权威协议，不恢复无密码身份入口。

## 验证
实际通过：规则/历史/源代码/产物检查、Go/race，真实三依赖/四服务/账号与全部协议、Windows/Linux 各 9/9 浏览器，包含真实 WebGL2 深度、镜头/相对移动/本地资源、无 GL 与丢失上下文拒绝；双人 3D 正视/环绕截图已查看。产物漂移负测证实默认检查不改写文件。所有回归保留，编译或旧 2D 结果未代替 3D 验收；远端仍需另行授权 Push 才能证明。

## 重评条件
需要大型场景资产、真实地形/垂直物理、触屏移动、性能预算或独立客户端时，再比较资源构建与引擎方案；不能为了跑测试关掉 3D 或替换为静态截图。
