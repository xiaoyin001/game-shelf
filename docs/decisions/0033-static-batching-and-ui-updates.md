# ADR-0033：静态石块批处理与变化驱动的界面更新

状态：采用（2026-10-27，正式门禁失败后先调查、再决策；Windows与固定SDK双CPU Linux候选单playable均21/21，最慢29.6秒，仍不能放行默认27秒余量/两轮门禁）。接续[ADR-0032](0032-collection-camp-display.md)，不改变玩法、物理、存档、图形质量、帧率目标或验收上限。

后续[ADR-0034](0034-avatar-instancing.md)在本记录基础上继续批处理角色部位，以争取完整两轮预算；本记录的候选21/21但29.6秒边界作为历史保留，不改成已放行。

## 背景
7d32406在Windows真实服务/20例和race通过，但最终commit默认完整preflight失败：source/race成功，playable协议成功、浏览器15/20（7.0m），新增寻宝/展台和原NPC/跳跃/碰撞/presence超30秒。本轮project与缓存回收为0，未生成推送证据，未Push。

实际trace中多项第二页面的账号fill分别5.29/6.73/9.66/11.23秒，截图约2.5–3.1秒；不是存档接口拒绝，也不能只凭mailbox日志称GPU崩溃。只读回放旧271b7b3：相同固定SDK、2CPU/4GiB/无swap和真实依赖的单playable job，19/19（4.6m，最慢29.3秒）通过；这不是默认两轮preflight，也不是新版通过。宿主采样负载76%，不能据此证明宿主是唯一根因，未做统计性能对比。

## 比较
- 保持每帧/每100ms重写相同属性、静态石头逐个draw：简单，但增加无效DOM变更与驱动调用，不采用。
- 降低30/12fps、关闭阴影/改分辨率、冻结图形、截图替代3D、延长30秒或总预算/增加重试：改变体验或掩盖门禁失败，不采用。
- 静态同几何/材质的36块石头用一个真实InstancedMesh绘制；界面只在派生值实际改变时写DOM；把过长新增浏览器流程分为两个各自完整、独立注册/探索的闭环：采用。原模型几何/位置/缩放、材质、阴影、动态绘制与网络频率保持，全部原断言继续运行。

## 决定
1. 原野26块石头和营火10块石头共用单位十二面体，以实例矩阵重建各自原始半径、Y缩放与坐标；真实3D仍一次性绘制所有实例，保留投射/接收阴影并计算实例包围球。不动layout、碰撞、画质或动态角色，不用渲染目标截图冒充场景。结构上36次同材质绘制合为1次，不把这一结构变化冒称已经实测提速。
2. 展台UI只在拥有者、公开布置、页签或可编辑状态改变时更新。在线列表/个人坐标/静态计数只在实际数据改变时更新；资源倒计时仍随服务器时间推进，文本内容变化时立即呈现。渲染的只读高度/模式/模型计数等属性不重复写相同值，真实renderCount仍每次GPU绘制递增。相机、物理、输入和轮询不节流。
3. 新探索用例恢复为“真实领取→两步调查→中途退出续接→收藏/故事→密码重登仍在”的完整独立流程；新展台用例从全新账号真实寻宝解锁，再布置/收起/参观/密码重登同时验证收藏与布置，不复用前一个用例的账号或种入伪进度。增加到21例，不删除原20例的任何行为或截图，保留独立上下文正常关闭。
4. 新增真实只读指标检查实例数和批次数，原WebGL2深度/镜头/角色同步/失去上下文断开继续覆盖；空闲采样窗口额外观察展台和稳定HUD没有无意义DOM重写，不改变原12fps的真实绘制断言。
5. 不更改CI运行器、资源、SDK、27秒本地余量、30秒/零重试或总预算。最终新版仍须真实默认完整preflight全部通过；旧基线单job只用于调查，不能生成/代替推送记录。基线第一次因外层日志路径错误中断，未完成报告不算结果；只在确认其PID不存在、无所属资源后移除该轮过期锁，后续70f3a18b才是完成的单job对照。
